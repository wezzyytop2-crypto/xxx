## 🔧 Что дальше?

### Минимум для запуска (1-2 часа):
1. Добавить EXPANDED_FAMILIES в `lib/dictionary.ts`
2. Обновить SET_BLUEPRINTS
3. Bump BUILT_IN_VERSION в `lib/db.ts`

### Полная интеграция (4-6 часов):
Смотри **INTEGRATION_GUIDE.md** для пошагового руководства

### Проверить:
```bash
# TypeScript ошибки
npm exec tsc -- --noEmit

# Запустить dev сервер
npm run dev

# Посетить новую страницу
# http://localhost:3000/grammar
```
