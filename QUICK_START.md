# LIMBI — Готово к использованию! 🚀

Приложение полностью настроено и готово для личного использования. Вот что было добавлено:

## ✨ Новые возможности

### 📊 Полная статистика
- Переходи на страницу **Статистика** (кнопка на главной)
- Видишь прогресс, точность, уровень и XP
- Экспортируй данные в JSON для резервной копии

### 📥 Импорт слов из CSV
1. Нажми **Новый набор** → **Импортировать из CSV**
2. Подготовь файл в формате: `term,translation,example,note,partOfSpeech`
   - Например: `hello,привет,Hello there!,Вежливое приветствие,expression`
3. Загрузи файл — система создаст набор автоматически

### 🎮 Три режима обучения
- **Flashcards** — быстрые свайпы влево/вправо
- **Learn** — фокус на сложных словах
- **Write** — ручной ввод перевода

### 🎯 Геймификация
- За каждую проверку +10 XP
- Уровень = текущий XP / 100
- Видишь уровень на главной странице

### 💾 Экспорт и резервная копия
- Все данные хранятся локально на устройстве
- Экспортируй в JSON через страницу Статистика
- Скопируй файл резервной копии в безопасное место

## 🚀 Быстрый старт

```bash
npm install
npm run dev
# Открй http://localhost:3000
```

## 📱 Установка как приложение
1. На мобильном: нажми меню → **Установить приложение**
2. На ПК/планшете: используй кнопку install prompt

## 📚 Встроенный словарь
- 250+ слов в 11 категориях
- Все категории содержат примеры и заметки
- Каждая категория имеет 11 вариантов колод для разного подхода

## 💡 Советы по использованию
1. **Ежедневная практика** — 15-30 минут в день лучше, чем много один раз
2. **Чередуй режимы** — Flashcards для скорости, Learn для сложного, Write для активной речи
3. **Создавай свои наборы** — CSV import для персональных слов
4. **Сохраняй резервные копии** — Regular export for safety

## 🐛 Известные вещи
- Всё работает оффлайн — интернет не требуется
- IndexedDB очищается при очистке данных браузера
