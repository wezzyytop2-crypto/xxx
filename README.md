# LIMBI

Мобильное PWA-приложение для изучения румынского языка без регистрации и без сервера.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Возможности

- 📚 **250+ слов** в 10+ категориях (встроенный словарь)
- 🎮 **Три режима обучения**: flashcards, learn, write
- 📊 **Расширенная статистика** с уровнями и XP
- 💾 **Экспорт/импорт** данных и CSV для создания собственных наборов
- 🗣️ **Web Speech API** для озвучки иностранных слов
- 🎯 **SM-2 алгоритм** спланированного повторения
- 📱 **Полный оффлайн-режим** с локальным хранилищем IndexedDB
- 🔄 **Синхронизация в фоне** (подготовка для облачной синхронизации)
- ⚡ **Быстрая и плавная** мобильная версия
- 🌐 **Установка на главный экран** как приложение

## Режимы обучения

### Flashcards
Быстрое повторение с свайпами. Влево — не знаю, вправо — знаю.

### Learn
Фокус на сложных карточках. Пересчитываются по алгоритму SM-2.

### Write
Ручное введение перевода с проверкой и нечувствительностью к опечаткам.

## Импорт и экспорт

### Экспорт
- Все данные автоматически сохраняются локально в IndexedDB
- Скачать резервную копию через кнопку "Экспортировать" на странице статистики

### Импорт из CSV
1. Создай CSV файл в формате: `term,translation,example,note,partOfSpeech`
2. На странице создания набора нажми "Импортировать из CSV"
3. Большие наборы автоматически обрабатываются

## Деплой

### Vercel

1. Импортируй репозиторий в Vercel.
2. Framework Preset: `Next.js`.
3. Build Command: `npm run build`.
4. Output не менять.
5. После деплоя PWA, IndexedDB и оффлайн-режим продолжат работать на клиенте.

### Локальная сборка production

```bash
npm run build
npm run start
```
