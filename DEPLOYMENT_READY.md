# 🚀 LIMBI — Полностью готовое приложение

## Что было сделано "под ключ"

### ✅ Функционал для личного использования

#### 1. **250+ слов в словаре**
   - 11 категорий (приветствия, учёба, путешествия, дом, еда, покупки, здоровье, время, погода, люди, эмоции, глаголы)
   - Каждое слово с примерами и заметками
   - 11 вариантов колод для разного подхода

#### 2. **Три режима учебы**
   - **Flashcards** — быстрые свайпы
   - **Learn** — сложные слова
   - **Write** — ручной ввод

#### 3. **Полная статистика**
   - Прогресс по словам
   - Точность ответов
   - Уровни и XP (геймификация)
   - Экспорт данных в JSON

#### 4. **Импорт своих слов**
   - CSV format: `term,translation,example,note,partOfSpeech`
   - Один клик — новый набор создан

#### 5. **Работает везде**
   - Оффлайн (без интернета)
   - На телефоне, планшете, ПК
   - Установка как нативное приложение

### 💡 Как использовать

**День 1:** 
- Открой приложение
- Выбери любой встроенный набор
- Учи в режиме Flashcards (10-15 минут)

**День 2:**
- Повторяй "просроченные" карточки (Learn)
- Пробуй Write режим

**День 7:**
- Экспортируй прогресс (резервная копия)
- Добавь свой набор через CSV

### ⚙️ Что внутри

- **Next.js 14** с App Router
- **React 18** + TypeScript strict
- **IndexedDB** для локального хранилища
- **SM-2 алгоритм** для умного повторения
- **Service Worker** для оффлайна
- **Tailwind CSS** для дизайна

### 📊 Один пример дня

```
09:00 - Flashcards (5 минут)   [+5 XP]
14:00 - Learn mode (10 минут)  [+10 XP]
18:00 - Write mode (5 минут)   [+5 XP]

Итог: +20 XP в день
Примерно 5 дней до следующего уровня
```

### 🔒 Данные безопасны

- Всё остаётся на твоём устройстве
- Нет облака, нет регистрации
- Можешь экспортировать когда угодно
- Синхронизация через JSON файлы
