# Финальный промпт для полной интеграции учебной системы

## Что уже сделано

Создана основа полнофункциональной учебной системы румынского языка:

### 1. Грамматика (lib/grammar.ts)
- 30+ грамматических правил с объяснениями на русском
- Категоризация по темам
- Примеры и подсказки для каждого правила

### 2. Расширенный словарь (lib/expanded-dictionary.ts)
- 300+ новых слов и фраз в 11 тематических категориях
- Высокий уровень практичности и полезности

### 3. Система адаптивных повторений (lib/study-system.ts)
- SM-2 алгоритм для интервального обучения
- Приоритизация карточек по срочности и сложности
- Система XP и уровней
- Фильтрация карточек (due, weak, new, mastered)

### 4. Интерфейс
- Экран грамматических правил с фильтрацией (components/screens/grammar-rules-screen.tsx)
- Компонента для режима тестирования (components/cards/quiz-session.tsx)
- Селектор режимов обучения (components/study-mode-selector.tsx)
- Обновлённая нижняя навигация с кнопкой "Грамматика"

## Примеры интеграции

### Пример 1: Использование SM-2 в study flow
```typescript
import { calculateSM2NextReview, createSessionStats } from "@/lib/study-system";

// После ответа пользователя
const quality = getQualityFromResponse(userAnswer); // 0-5
const newSM2State = calculateSM2NextReview(quality, currentProgress);

// Обновить прогресс карточки
cardProgress.dueAt = newSM2State.nextReview;
cardProgress.intervalDays = newSM2State.interval;
cardProgress.ease = newSM2State.easiness;
```

### Пример 2: Фильтрация карточек для сессии
```typescript
import {
  filterDueCards,
  filterWeakCards,
  filterNewCards,
  sortCardsByPriority
} from "@/lib/study-system";

// Для режима focus - приоритет на due
const focusCards = sortCardsByPriority(filterDueCards(allCards));

// Для режима learn - новые карточки
const learnCards = filterNewCards(allCards);
```

### Пример 3: Режим quiz
```typescript
import { QuizSession } from "@/components/cards/quiz-session";

<QuizSession
  card={currentCard}
  allCards={setCards}
  onAnswer={(isCorrect) => handleQuizAnswer(isCorrect)}
  cardIndex={sessionIndex}
  totalCards={session.cards.length}
/>
```
